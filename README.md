# 🎧 The Experience

Music is being built with one simple idea:

**music should feel as good as it sounds.**

The application combines a modern Android architecture with a focused interface designed around the listening experience.

### Simple

### Current foundation

- 🎨 Modern Jetpack Compose UI
- 🧩 Material 3 design system
- 🧭 Compose Navigation
- 💉 Dependency injection with Hilt
- 💾 Persistent local storage
- 🔄 Reactive state with Coroutines & Flow
- 🌙 Application theming
- 📱 Edge-to-edge interface
- 🚀 Modern Android startup experience
- 🏗 Layered project architecture
